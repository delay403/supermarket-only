## 0. 合集是怎么组织的

这是一个 **单 Unity 工程、多玩法合辑（game center）**：所有玩法共用一套启动器、存档、主页、经济与养成，通过配置决定「这个包体里有哪些游戏模式」。

## 1. 爬塔（Tower）— 攀爬 + 塔顶滑翔结算

**一句话**：按住向上爬一座有限高度的塔，登顶后起跳滑翔，用「水平滑翔距离」换金币与钻石，通关发奖牌解锁更高塔。

- **核心循环**：进图 → 走 `TowerClimbEntryPoint` → 自动进入攀爬（`ClimbController.EnterClimb`，进入即开启 `AutoAscendEnabled`）→ 只能向上，体力持续消耗 → 到达塔高上限后在塔顶开宝箱 / 点 HUD「跳跃」→ 空翻/滑翔 → 触地结算金币、钻石、奖牌。
- **塔体**：按段（`segmentHeight` 默认 10m）分块对象池生成，只保留玩家上下可视窗口内的段；有限高度时最高一格换成 `towerTopPrefab`（可挂塔顶宝箱 `TowerSummitChestZone`）。
- **体力**：`Stamina`（`staminaMax` / `staminaDrainPerSecond`）；耗尽不失败，只把攀爬速度乘 `climbSpeedWhenStaminaEmptyMultiplier`（默认 0.2）。
- **滑翔分支**：爬升高度 < `minGlideHeightMeters`（25m）→ 只下落，**无滑翔流程、无结算**；≥ 空翻阈值（39m）→ 走 Animator「空翻」再接坠落/滑翔；滑翔期间可切「滑翔自由轨道」。
- **结算公式**（[RewardCalculator.cs](Assets/Game/Scripts/Economy/RewardCalculator.cs)）：
  - 金币 = `(基础500 + ΣcoinsAdd) × max(0, 1 + ΣcoinsMul + 地图金币修正) × 水平滑翔距离 ÷ 1000`（100m ≈ 50 币）
  - 钻石 = `floor(水平滑翔距离 ÷ 1000 × gemsPer1000m)`
  - 激励 buff「双倍金币」「双倍攀爬速度」可翻倍（`AdBuffService`）
- **地图与奖牌**（3 张，奖牌是全局资源）：

| mapId | 名称 | 塔高 | 解锁奖牌 | 金币修正 | 通关奖励 |
| --- | --- | --- | --- | --- | --- |
| map_1 | 最高铁塔 | 500 m | 0 | 0 | 2 奖牌 |
| map_2 | 塔吊工地 | 1000 m | 10 | +3 | 2 奖牌 |
| map_3 | 摩天大楼 | 1500 m | 30 | +6 | 10 奖牌 |

- **存档**：`currentMapId` / `unlockedMaps` / `medals` / `bestGlideDistanceMeters` / `towerProfile`；另有竞技场排行榜（含虚拟玩家库 `VirtualPlayerDatabase`）。
- **入口**：主页「爬塔」卡片 → 按存档地图进入 `Map1/2/3`。

证据：[ClimbController.cs](Assets/Game/Scripts/Tower/ClimbController.cs)、[TowerManager.cs](Assets/Game/Scripts/Tower/TowerManager.cs)、[Stamina.cs](Assets/Game/Scripts/Tower/Stamina.cs)、[GlideController.cs](Assets/Game/Scripts/Glide/GlideController.cs)、[MapDef.cs](Assets/Game/Scripts/Maps/MapDef.cs)、[Map_1.asset](Assets/Game/Modes/Tower/Content/Configs/Activity/Maps/Map_1.asset)

## 2. 钓鱼（Fishing）— 连点收杆 + 鱼类图鉴

**一句话**：走到钓点开始钓鱼，连点「收杆」把进度条拉满，按概率抽中一条鱼换金币，并逐步填满图鉴。

- **核心循环**：进 `FishingZone` 触发器 → HUD「钓鱼」开始（锁定站位、禁用移动，1s 后进入收杆态）→ 连点「收杆」→ 进度满 → 按权重抽鱼 → 金币入账 + 图鉴记录 → 可继续/取消。
- **操作**：纯连点，无 QTE、无瞄点（抛竿落点由区域配置自动生成），连点最小间隔 0.15s；编辑器可用 `F`（钓/收杆）/`X`（取消）测试。
- **概率**：每个鱼池槽位一组千分比权重表（默认 `{200,200,150,150,90,90,90,20,10}`；有「特殊钓获加成」时换成另一套 `{150,150,150,150,110,110,110,40,30}`），场内提供「概率公示」面板。
- **数值**：单次收杆进度 =`(totalPower + ΣprogressAdd) × scale`，`totalPower = baseStrength + ΣfishingPowerAdd + baseStrength × ΣfishingPowerMul`；钓获金币 = `rewardCoins × (1 + ΣfishingCoinMul) × catchCoinMultiplier`（免费奖励可开 ×10）。
- **内容规模**：4 个分区（初级/中级/高级/特级池塘）、30 条鱼（`FishDef 0–29`，按品质分级）、15 根鱼竿（`RodDef 0–14`，鱼竿商店）。
- **养成**：基础力量由「力量训练池」挂机/免费奖励/钻石解锁提升（默认每 10s 一档）；装备宠物/翅膀/拖尾/角色/鱼竿都算进钓力。
- **图鉴**：`fishDiscoveries[{fishId, catchCount}]`，首次钓获记为发现；可把钓到的鱼佩戴在背部展示。
- **免费奖励**：力量奖励 +1000；自动钓鱼通行证 30 分钟；分区解锁阶梯奖励；力量训练场每日奖励/钻石解锁。
- **入口**：主页「钓鱼」→ `FishScene`；无独立模式内主页，直接在场景 HUD 操作。

证据：[PlayerFishingController.cs](Assets/Game/Scripts/Fishing/PlayerFishingController.cs)、[FishingService.cs](Assets/Game/Scripts/Fishing/FishingService.cs)、[FishingCatchProbability.cs](Assets/Game/Scripts/Fishing/FishingCatchProbability.cs)、[AutoFishingService.cs](Assets/Game/Scripts/Fishing/AutoFishingService.cs)、[FishingModeSaveData.cs](Assets/Game/Scripts/Save/FishingModeSaveData.cs)

## 3. 摧毁城市（Destroy City）— 产燃料 → 灌核弹 → 发射

**一句话**：放置类循环：生产燃料、把燃料搬进发射井灌注核弹、升级核弹当量，然后发射导弹亲手操控落点，看房屋成片下沉换金币。

- **核心循环**：燃料生产器自动/手动产出 → 地上生成燃料实例（= 燃料经验的实体）→ 玩家拿起（可合并经验）→ 走到发射井「投放燃料」→ 灌注核弹经验、自动升级 → 「发射」→ 导弹三段飞行 → 玩家在下降段操控落点 → 爆炸按半径清房 → 金币飞入 HUD。
- **核弹**：10 级，Lv1「纸壳核弹」爆炸半径 12m → Lv10「熔岩火箭核弹」354m；**每次发射后核弹重置回 Lv1**（消耗式），需要重新攒燃料。
- **燃料**：14 级（`FuelDatabase.DefaultMaxLevel`）；4 个生产器 = 手动 + 自动 I/II/III，各 20 级、自动周期约 2s、升级消耗金币（1 级升级 200 → 满级 227 万+）；解锁策略含「免费奖励解锁一次」。
- **发射表现**：井盖关闭 0.75s → 警报 2s → 井盖开启 → 导弹升起 2.5m → 飞行 3.5s（上升/巡航/下降），下降段可操控落点（限半径 25m）；可在「玩家视角 / 导弹视角」间切换。
- **结算**：摧毁比例 = `爆炸半径 ÷ 城市规模(200m)` 并 clamp 到上限；比例 ≥ 0.5 记一次「摧毁城市」；每栋被摧毁房屋 **500 金币**（金币飞入特效逐枚入账）。
- **地图**：目前仅 1 张 —— 城市 Alpha（`destroy_city_map_1`，地图等级 1，范围 200m）。注意 `DestroyCityMapDef.baseCoinReward`（1000）与 `NukeDef.coinRewardMultiplier` 目前**运行时未被读取**，实发金币只来自「每栋房 500」。
- **免费奖励**：免费奖励解锁燃料生产器、按进度档位发免费金币；首次发射/首次升级生产器触发折扣礼包。
- **入口**：主页「摧毁城市」→ `DestroyCityScene`（无独立结算面板，全程在一个场景内挂机推进）。

证据：[FuelProducerService.cs](Assets/Game/Scripts/DestroyCity/FuelProducerService.cs)、[PlayerFuelCarryController.cs](Assets/Game/Scripts/DestroyCity/PlayerFuelCarryController.cs)、[NukeLauncherController.cs](Assets/Game/Scripts/DestroyCity/NukeLauncherController.cs)、[NukeHouseDestructionService.cs](Assets/Game/Scripts/DestroyCity/NukeHouseDestructionService.cs)、[NukeLaunchService.cs](Assets/Game/Scripts/DestroyCity/NukeLaunchService.cs)、[DestroyCityModeSaveData.cs](Assets/Game/Scripts/Save/DestroyCityModeSaveData.cs)

## 4. 躲避虫子（Worm Dodge）— 多层跑酷躲多节虫

**一句话**：在一座多层的场景里往上跑，躲开沿路径巡逻、会锁定追击的多节虫，逐层拿金币，跑到终点即通关。

- **核心循环**：消耗 1 点体力开局 → 虫子从路径起点出发巡逻 → 玩家逐层向上，穿过「楼层结算区」记录层数并发金币 → 进入安全区（检查点）可甩掉追击并复活点记录 → 抵达终点区 = 胜利。
- **体力**：上限 5，每 10 分钟恢复 1 点，免费领取 +5；`TryConsumeForRun` 不足则不能开局。
- **虫子 AI**（多节虫链：头 + 多节身体）：沿 `WormPath` 巡逻，索敌半径 14m、允许高度差 4m（不跨层锁定），追击到目标出圈或进安全区；结束追击后有 15s 只巡逻不索敌的冷却；巡逻时会按权重挑目标（AI/玩家）。
- **失败与复活**：被虫咬住或死亡区淘汰 → 结算；每局可用一次免费奖励复活（给无敌时间并把虫子的索敌暂停 2s，传送回最近检查点）。
- **道具**：金币道具（25–75）、加速、超级跳跃（随机生成器 + 脚下持续特效）。
- **排行榜**：局内实时排行榜，参与者为场景中真实玩家 + AI（虚拟玩家数据）。
- **结算奖励**：本局金币按躲避虫子专属属性加成后入账，可免费翻倍；存档记录最高层数、通关次数、最快通关时间。
- **入口**：主页「躲避虫子」→ `EscapeWormScene`，模式内主页含角色选择/解锁 + 开始游戏。

证据：[WormDodgeDirector.cs](Assets/Game/Scripts/WormDodge/WormDodgeDirector.cs)、[WormChainMotor.cs](Assets/Game/Scripts/EscapeSnake/WormChainMotor.cs)、[WormDodgeStaminaService.cs](Assets/Game/Scripts/WormDodge/WormDodgeStaminaService.cs)、[WormDodgePickupConfig.cs](Assets/Game/Scripts/WormDodge/Pickups/WormDodgePickupConfig.cs)、[WormDodgeModeSaveData.cs](Assets/Game/Scripts/WormDodge/WormDodgeModeSaveData.cs)

## 5. 超市收纳（Supermarket Organize）— 第一人称整理货架

**一句话**：第一人称把散落一地的商品捡起来，按品类放回对应货架；全部上架且所有货架摆满即「整理完毕」。

- **核心循环**：进场景（可选模式内主页选难度）→ 地面随机散落商品（固定随机种子 20260707，可免费重随机）→ 拾取到手提区（容量随等级 4→16/32）→ 准星对准货架放置 → 匹配 `itemId` 才算正确 → 全部归位触发胜利结算。
- **操作**：第一人称视角（右摇杆转头），屏幕中心准星射线（8m）自动高亮可交互物，点击/触摸拾取与放置；手持物品可轮换；放置前有绿色预览位与「正确的货架 / 错误的货架」提示。
- **胜利条件**：地面剩余 0 + 手持 0 + 已满货架数 = 总货架数 + 已放置数 = 总格子数（**无倒计时**）。
- **难度**：2 档 —— 杂货店、超级市场（切换场景内的货架/商品布局，各消耗 1 点体力）。
- **技能（金币升级）**：价格扫描器（同类高亮 8s）、磁铁（半径 10 吸取）、X 射线（货架提示 6s）、自动存货员（自动上架）；属性：购物篮容量、移动速度、拾取范围。
- **扫地机器人**：免费解锁 300s，每 15s 自动搬一件商品（NavMesh 寻路）。
- **奖励**：每放对 1 件 +3 金币，摆满一个货架额外 +30 金币；存档记录总场次/胜场/最快用时与各技能等级。
- **内容规模**：223 个商品定义（12 组 × 若干，如「奶香鱼肉罐头」「可乐汽水」）。
- **免费奖励**：扫地机器人、体力补充（配置里 `staminaEnabled=0`，逻辑保留 UI 关闭）、地面物品重随机。

证据：[SupermarketOrganizeDirector.cs](Assets/Game/Scripts/SupermarketOrganize/SupermarketOrganizeDirector.cs)、[SupermarketOrganizeService.cs](Assets/Game/Scripts/SupermarketOrganize/SupermarketOrganizeService.cs)、[SupermarketOrganizeConfig.asset](Assets/Game/Modes/SupermarketOrganize/Content/Configs/SupermarketOrganize/SupermarketOrganizeConfig.asset)、[SupermarketOrganizeModeSaveData.cs](Assets/Game/Scripts/Save/SupermarketOrganizeModeSaveData.cs)

## 6. 动物医院（Animal Hospital）— 第一人称值班 + 理智管理

**一句话**：第一人称当班医生，按流程接待并治疗动物病人，同时躲避/处理天花板异物、黑影、着火、粘液等异常，理智归零就失败。

- **核心循环**：按天推进（无昼夜切换，只有「第 N 天」）。每天到院 4–12 名病人，每 30–60s 来一位。
  - **接待链**：报告 → 拍照 → 电脑登记 → 打印 → 填写入院表 → 接入病人（异常病人拍完照后会发狂）。
  - **病房链**：手术 → 分析机 → 病房电脑 → 病房显示屏 → 用**正确药物**治疗病人。
  - 班次结束到「换班结算台」交互 → 日结算（完美 / 优秀 / 普通），要求当天至少治好 1 位。
- **操作**：第一人称，准星对准物体**长按**交互（键盘 `E` 或 HUD 按住按钮），各类交互有不同长按时长（0.8–1.5s）。
- **理智（Sanity）**：上限 100，起始 70；按配置周期被动衰减；看天花板异物、走廊粘液、病房着火都会持续扣；被黑影/异常病人打一次扣 5；低于一半播放心跳。理智归零 → 死亡面板，可免费恢复 50 点。
- **异常事件**：每局每天最多 3 次，概率逐天提升（第 1 天 0%，第 2 天 20%，之后每天 +10%，上限 50%）。
- **道具战斗**：电棍（默认解锁）、电击器 500、手枪 500、灭火器 1000、冷冻枪 2000 金币；黑影/异常病人 10 点血，道具每次伤害 5，灭火器/冷冻枪为持续光束。
- **奖励**：每治好 1 位 +10 金币，每处理 1 次异常 +10 金币；日结算可免费双倍。
- **存档**：`currentDay`、`patientsTreatedTotal`、`patientsLostTotal`、`sanity/maxSanity`、各道具解锁标记、`profile`。
- **入口**：主页「动物医院」→ `AnimalHospitalScene`（进入后自动开始当天流程）。

证据：[AnimalHospitalConfig.asset](Assets/Game/Modes/AnimalHospital/Content/Configs/AnimalHospital/AnimalHospitalConfig.asset)、[AnimalHospitalEnums.cs](Assets/Game/Scripts/AnimalHospital/AnimalHospitalEnums.cs)、[AnimalHospitalDirector.cs](Assets/Game/Scripts/AnimalHospital/AnimalHospitalDirector.cs)、[AnimalHospitalService.cs](Assets/Game/Scripts/AnimalHospital/AnimalHospitalService.cs)、[AnimalHospitalModeSaveData.cs](Assets/Game/Scripts/Save/AnimalHospitalModeSaveData.cs)

| 模式 | 视角/操作 | 单局结构 | 失败条件 | 主要产出 | 局内奖励入口 |

**最复杂的实现是「超市收纳」**：代码量、文件数、UI 面板数都第一（Home / Detail / Upgrade / UpgradeRow / UpgradeDetail / SkillHud / SkillSlot / SweepRobot / Stamina / Result / InteractionHud / ShelfFeedback …），并且横跨物品物理掉落与落定、地面物品遮挡剔除、随机生成、货架网格、手持堆叠、准星交互、4 技能 + 4 属性升级、扫地机器人 NavMesh AI、2 档难度。

**系统耦合最深的是「动物医院」**（代码量第二）：两条流程状态机（接待 6 步 / 病房 6 步）+ 5 类异常（天花板、病房着火、走廊粘液、黑影、异常病人）+ 5 种道具战斗 + 理智系统 + 日程与日结算 + 3 套 SO 目录，单个 `AnimalHospitalService` 就有 1,219 行。

单文件最大的几个：`AIFakeWormDodgeBehavior` 1,621 行、`GlideController` 1,570 行、`AnimalHospitalService` 1,219 行、`AnimalHospitalPatient` 1,023 行、`WormChainMotor` 939 行、`SupermarketOrganizeService` 833 行。编辑器侧还有 `SupermarketOrganizeSceneSetupUtility` 1,185 行、`DestroyCitySceneSetupUtility` 1,008 行、`WormDodgeContentBuilder` 962 行——说明这几个模式的场景装配工作量也最大。

### 8.2 「剧情」：目前**没有任何模式有真正剧情**

- 仓库只有一套**通用过场框架**：`Assets/Game/Scripts/Cutscene`（4 文件 / 381 行）= `CutsceneSequenceController`（`DialogueLine{startTime, speakerName, text, displayDuration}` + 摄像机 + NPC + 跳过按钮）、`CutsceneDialogueUi`、`CutsceneCameraController`、`CutsceneActorController`。
- 全仓库**唯一**在场景里挂载过它的地方是 `SupermarketOrganizeScene`，而该物体的 `dialogueLines: []` 是**空数组**——一句台词都没有；超市收纳的开场实际走「按计时占位」（`SupermarketOrganizeIntroController`）。
- 没有视频（`*.mp4/*.webm/*.mov` 0 个）、没有 Timeline（`*.playable` 0 个）、没有新手引导/剧本/台词数据（检索 `新手|引导|开场|章节|旁白|台词` 只命中注释）。

若把「剧情/内容包装」理解为世界观与内容完整度，排序是：

1. **动物医院**——唯一有「角色 + 事件 + 进程」骨架的模式：11 位有名字的病人（咯咯、嘟嘟、噜噜、库库、拉拉、呱呱、巴巴、理理、舒舒、切切…）、11 种病症（头疼/胃病/眼干/发烧/擦伤/淤青/割伤/烧伤/皮肤红疹/过敏皮炎/低血糖）、10 种药品（草药/瓶装丸药/滴眼液/体温计/退烧药/医疗急救包/绷带/白色药膏/黄色药膏/枫糖浆），按天推进 + 日结算评级（完美/优秀/普通），外加「异常病人 / 黑影」的诡异向设定。
2. **钓鱼**——30 种鱼 + 4 个池塘 + 图鉴收集，但没有情节。
3. **超市收纳**——223 个商品名（只是货品，无叙事）。
4. **爬塔**——3 张地图名（最高铁塔/塔吊工地/摩天大楼）+ 通关奖牌。
5. **躲避虫子 / 摧毁城市**——几乎没有包装内容，纯玩法。

结论：**要「最复杂」选超市收纳，要「最有内容/叙事骨架」选动物医院；而真正的剧情（台词、章节、过场演出）在这个仓库里尚未开始做，只有现成的过场播放器可用。**

## 9. 读代码时的几点提醒

- **融合包体**：`Hybrid = Tower | Fishing` 共用一份存档，但每个模式有独立 `ModeScopedProfile`（金币/装备可各自独立），切模式时按 profile 切换。
- **模式启用是双保险**：`GameProductSettings.IsXxxContentEnabled`（静态）与 `GameplayModuleContext.IsModuleActive(...)`（运行时按主页选中的卡片）都要满足，模式才会真正跑起来。
- **HUD/装备按模式裁剪**：`GameModeHudVisibility` 与 `GameModeEquipmentBonuses` 控制每个模式显示哪些入口按钮、吃哪些装备加成（钓鱼模式额外显示鱼竿商店与图鉴）。
- **数值主要在 ScriptableObject 里**：玩法手感、经济、体力和奖励档位大量写在 `GameBalanceConfig.asset` 与各模式 `Content/Configs/**` 的 .asset 中，改数值优先看配置而不是代码常量。
